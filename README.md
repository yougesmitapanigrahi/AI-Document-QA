# AI-Powered Document Question Answering System

A Python project for asking questions about uploaded documents. The planned
Streamlit interface will connect document processing, vector search, and
question-answering components in `src/`.

## Project structure

- `app.py` — Streamlit application entry point.
- `src/document_processor.py` — document text extraction and preparation.
- `src/vector_store.py` — embedding storage and similarity search.
- `src/qa_engine.py` — answer generation using retrieved document context.

## Setup

Create and activate a Python virtual environment, then install dependencies
from `requirements.txt`. Application logic has not yet been implemented.
